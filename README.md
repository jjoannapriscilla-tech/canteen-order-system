# 🍽️ Canteen Order Management System

A simple Python-based console application for managing food orders in a canteen. This project was developed collaboratively to practice Python programming, modular programming, and Git/GitHub collaboration.

## 📌 Overview

The Canteen Order Management System allows users to browse available food items, search for food, create an order, manage ordered items, and calculate the total bill.

The project is divided into separate Python modules to keep the code organized and easier to maintain.

## ✨ Features

- 📋 View the available food menu
- 🔍 Search for food items
- ➕ Add food items to an order
- ➖ Remove food items from an order
- 🧾 View the current order
- 💰 Calculate the total bill
- 🚪 Exit the application
